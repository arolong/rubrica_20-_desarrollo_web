# Sistema de Gestion de Activos Tecnologicos (MVP)

Proyecto academico que presenta un prototipo de sistema para administrar activos tecnologicos: inventario, categorias y mantenimientos. El enfoque es demostrar estructura, flujo visual y modelo de datos base, sin implementar toda la logica de produccion.

Finalidad: validar la viabilidad del sistema, comunicar el alcance del MVP y servir como base para las entregas de propuesta, solucion, diseno visual, herramientas y muestra de codigo.
