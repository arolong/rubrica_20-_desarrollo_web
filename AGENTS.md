# Registro de prompts y skills 

Este documento resume el trabajo colaborativo del proyecto con un enfoque 50% IA y 50% humano. Se listan los prompts clave usados con la IA y las decisiones humanas que guiaron el desarrollo.

## Prompts utilizados (IA)
- "Genera un dashboard MVP para gestion de activos con tarjetas, tabla y formulario rapido."
- "Crea rutas separadas para dashboard, activos, detalle de activo, categorias y mantenimientos en Next.js App Router."
- "Define un esquema Prisma para Activos, Categorias y Mantenimientos con enums de estado y tipo."
- "Ajusta estilos con Tailwind para una estetica sobria y academica."


## Decisiones humanas (50%)
- Seleccion del enunciado #2 y enfoque MVP/adelanto segun requerimientos.
- Definicion de modulos base: Activos, Categorias y Mantenimientos.
- Eleccion de stack: Next.js + Tailwind + Prisma + SQLite.
- Validacion del alcance y de los entregables solicitados.
- Modelo de la estructura del prototipo UI en Next.js

## Skills aplicadas
### IA
- Prototipado de UI en Next.js (App Router).
- Modelado inicial de datos con Prisma.
- Estructuracion de paginas y rutas.

### Humano
- Analisis de requerimientos y priorizacion del MVP.
- Curaduria de campos minimos para activos.
- Control de alcance, tiempos y entregables.
- Revision final del contenido presentado.
